# /brainstorm

Turn an idea or problem into an approved design before building.
Read `docs/process/workflow.md` and, for new or unclear projects, start with
`docs/process/start-here.md`. Ask a few targeted questions, summarize
assumptions, name trade-offs, and write the agreed design to a spec file using
the scaffold in `docs/process/design-template.md`. Mark anything underspecified
as `[NEEDS CLARIFICATION: <question>]` instead of guessing; resolve every
marker before approval. Do not start implementation before approval.
