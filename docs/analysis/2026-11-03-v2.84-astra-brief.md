## What changed against round 1 (verify each)

The first draft of this plan (6c272004) was blocked by a fresh Claude session (round 2a). The plan's section "Plan-Review" lists each of those findings and how it was answered. You review the revised plan.

**B, inert changes.**
- **The certificate is untouched.** `evidence_tree` is not changed, which removes the second glob matcher.
- **"Inert" is read only at the integration ref.** No ref, an unreadable ref or a broken file means nothing is inert.
- **Protected paths are never inert:**
  - everything `is_gate_path` knows;
  - all of `docs/process/` (overlays, the registry, `testing.local.json`, `gates.local.json`, the policies);
  - `.claude/`, `.github/`, `.specify/`, `.copier-answers.yml`.
- **Test inputs are never inert, path by path.** A path matching a stack path, a pin subject or a map `from` (via `process_git.path_matches`) stays code. There is no glob-against-glob comparison and no `ConfigError`. Projects must keep every file a test reads under a stack path or pin.
- **One owner, `quiet_paths`,** for `pre_push` and `finish`; both sides of a rename count. The gain is on the merge push; a branch push already selects no tests for out-of-stack paths.
- **`finish` merges a quiet range without a test run** and writes no merge certificate. This also holds for a bookkeeping-only range in projects without `areas.inert`.
- **A CLI `check_review.py quiet-range`** lets projects with their own hook (Kenni) adopt B.

**C, ui-check.**
- **A template gate, not core, with no module switch.** It runs everywhere and is silent without UI. There is no `_migrate` and no PyYAML-less path.
- **UI is detected from `areas.ui`** (union) and the design-contract registry `paths`.
- **Who owes the block:** a bound plan owes it when it declares a contract, or when the branch diff touches UI. A plan that only carries UI along writes `ui-check: n/a — <reason>`. There is no per-plan path attribution any more.
- **Axis `rules`:** names at least one existing repo path the plan checked against (the project's UI rule files), the reuse decision and the deviations with reasons, or `n/a — <reason>`. The gate checks only that the paths exist.
- **The start mode lives in `gate_modes.fold`:** a synthetic first row `shadow` + `observe` for template gates on the observe list that `gates.local.json` does not define. The sentinel skips `observe` in both loops, failures and guardrail breaches; the second fixes an existing gap at `gate_modes.py:365-367`. Promotion is `restore`.
- **No date-based grandfathering.**
- **The parser ignores fences and HTML comments.** A Spec Kit `plan-template.md` override carries the block as a commented skeleton.
- **Moved out:** the generic rules from the Kenni v5.3 alignment (#372) and nested anchors (#371).
