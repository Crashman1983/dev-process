2. **Counting.**
   - Is every red-path run counted exactly once under the right kind (first, retry_gates, retry_failed, retry_full, base, probe)?
   - Is the `red_path` per round right on every exit: green, flaky, gate-flaky, base-red, undefined, `dropped:<b>`, none-survived, conflicts, environment, push-rejected, aborted?

   - Flake rounds versus offender rounds.
4. **Config** (`testing_config._red_ids`): validation, defaults, duplicates, and that every config reader (pre_push, finish, dispatch) still loads a valid config.
5. **Docs** (`train.md` "The red path, measured", `testing.md` "Red tests"): do they say what the code does?
