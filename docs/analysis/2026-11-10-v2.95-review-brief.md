4. **`decide`:** marker with rc ≠ 0 ⇒ aborted; exit 0 wins; exit 75 at top level ⇒ aborted; no marker and no 75 ⇒ unchanged.
5. **Telemetry:** `red_path="suite-aborted"`, run kind `retry_abort`, `rounds[].aborts`, `train-phases` separating environment kinds and naming the first marker line with the count of consecutive trains.
