## Regressions-Linse

- **I4 (Standard an):**
  - Wer ein AC löscht, trägt es in `retired` ein. Wer AC umnummeriert, wird gestoppt.
  - Das ist eine neue Pflicht für jedes Projekt mit Registry. Sie folgt aus Owner-Entscheidung G auf #404; `stable_ids: false` an der Basis schaltet sie ab.
  - Der erste Lauf nach `--assign-ids` ist ohne Basis-IDs eine reine Neuvergabe und damit grün.
- **I4.4:** Ein verwaister Verweis innerhalb der Registry wird rot; heute prüft das niemand. Kennis Registry hat heute keine `#AC`-Verweise.
- **I4.7:** Eine Arbeit, die heute fälschlich ein fremdes `#AC19` belegen musste, muss das nicht mehr.
